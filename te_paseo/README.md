# Te Paseo!

## Requisitos

- Python 3
- No se necesitan paquetes externos. `requirements.txt` se incluye como referencia.

## Ejecutar

Desde la carpeta del proyecto, ejecuta:

```powershell
python app.py
```

La aplicación inicia el servidor local en <http://127.0.0.1:8000> y abre esa dirección en el navegador. Para detenerla, presiona `Ctrl+C` en la terminal.
